## Execute in Claude Code

Branch: `feat/pinned-notes`

One thing Claude Code flagged that the chat plan didn't anticipate: the sort key used `reverse=True` with bucket values (0 = pinned, 1 = unpinned), which silently reversed the intent — unpinned notes sorted first. Claude Code caught this when the tests failed and fixed it by negating the timestamps and dropping `reverse=True`, so ascending sort naturally puts pinned (bucket 0) before unpinned (bucket 1) with newer timestamps within each bucket.
